# Floyd-Warshall Algorithm Visualizer

A modular Python implementation and dynamic programming visualization of the **Floyd-Warshall All-Pairs Shortest Path Algorithm**, structured for academic and presentation purposes.

## 📁 Project Structure

The project is organized into clean, modular components:
- **`algorithm.py`**: Contains the core logic and state transition calculations for the Floyd-Warshall algorithm.
- **`ui.py`**: Handles graphical rendering, step-by-step matrix visualization, and interactive controls.
- **`main.py`**: The application entry point that integrates the UI and algorithm modules.
- **`README.md`**: Project documentation and usage guide.

## 🚀 Getting Started
